Dans ce tutoriel, nous allons découvrir le terminal Linux ensemble.

## Pourquoi le terminal ?

Le terminal est un outil puissant qui permet de contrôler votre ordinateur avec du texte plutôt qu'une souris.

## Commandes de base

- `ls` : lister les fichiers
- `cd` : changer de dossier
- `mkdir` : créer un dossier
- `pwd` : voir le dossier actuel

## Exercice pratique

1. Ouvrez votre terminal
2. Tapez `ls` et appuyez sur Entrée
3. Tapez `mkdir test` pour créer un dossier
4. Tapez `cd test` pour y entrer

Félicitations ! Vous avez utilisé le terminal.
