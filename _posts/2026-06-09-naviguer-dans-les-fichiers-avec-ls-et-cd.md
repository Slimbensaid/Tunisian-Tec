Dans ce tutoriel, apprenez à naviguer avec deux commandes essentielles.

## Lister les fichiers avec ls

```bash
ls                  # liste simple
ls -la              # liste détaillée avec fichiers cachés
ls /home/slim       # autre dossier
```

## Changer de dossier avec cd

```bash
cd Documents        # aller dans Documents
cd ..               # remonter d'un niveau
cd ~                # retourner au dossier personnel
cd /                # aller à la racine
```

## Exercice

1. Ouvrez le terminal
2. Tapez `ls`
3. Tapez `cd test`
4. Tapez `pwd`

Félicitations, vous savez naviguer !
